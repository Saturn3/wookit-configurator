Kit di prodotti configurabili per WooCommerce con confezione sempre inclusa, scelta per linea (categoria) e fragranza, landing page dedicata.

== Description ==

* Post type "Kit regalo" con landing page dedicata (/kit/nome-kit/) o shortcode [wookit_kit id="123"] (compatibile con Elementor).
* Confezione (prodotto WooCommerce) sempre inclusa nel kit.
* N prodotti da scegliere (predefinito 2): prima la linea (categoria configurata), poi il singolo prodotto.
* I prodotti si scelgono tramite fragranza: nome e anteprima letti da due custom field del prodotto (meta key configurabili, compatibili con ACF), più note olfattive facoltative.
* Testi, immagini e colori configurabili per ogni kit; sezioni hero e finale attivabili/disattivabili.
* Carrello: confezione + prodotti come righe collegate (prezzi e giacenze dei singoli prodotti), quantità sincronizzate, rimozione e ripristino a cascata, metadati nell'ordine.
* Compatibile con HPOS, Cart/Checkout Blocks e WPML (wpml-config.xml incluso).
